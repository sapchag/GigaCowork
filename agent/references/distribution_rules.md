# Справочники агента распределения заказов между логистами

## Группы логистов и должности

| Группа            | Должность сотрудника                              |
|-------------------|----------------------------------------------------|
| Авиаперевозки     | специалист по авиаперевозкам                       |
| ВЭД               | специалист по работе с ВЭД документацией           |
| Мультимодальные   | специалист по мультимодальным перевозкам           |

Сотрудники с должностями «ассистент» (специалиста, группы) и «руководитель группы»
**не распределяют заказы** — исключаются из выбора.

## Правило выбора группы по способу доставки и стране отправления

| Способ доставки       | Страна отправления      | Группа            |
|------------------------|-------------------------|-------------------|
| air                    | любая                   | авиаперевозки     |
| sea / truck / railway / direct truck | Китай (включая Гонконг) | ВЭД |
| sea / truck / railway / direct truck | не Китай               | мультимодальные   |
| отсутствует            | —                       | не определено     |
| не air                 | отсутствует             | не определено     |

## Способ доставки (допустимые значения)

- `air` — авиа
- `sea` — море
- `truck`, `direct truck` — авто
- `railway` — ж/д

## Статусы реестра Cloud

- `в работе` — заказ ведётся логистом (учитывается в загрузке)
- `confirm` — заказ подтверждён (в загрузку не входит)

## Текущее состояние сотрудника (1С)

- `Работает` — доступен к распределению
- любые виды отпуска (например «Отпуск», «Отпуск по уходу») — исключается
- `Уволен` — исключается

## Форма строки реестра Cloud (12 колонок в порядке)

1. Заказ
2. Поставщик
3. Бренд
4. Логист
5. Статус
6. Дата подтверждения
7. Cut-off
8. Дата получения УЛ
9. Страна отправления
10. Способ доставки
11. Документы получены
12. Комментарий

## Приоритет выбора логиста

1. Предпочтительный логист — чаще всех работал с этим поставщиком (история в Cloud),
   исключая сотрудников в отпуске, уволенных, ассистентов и руководителей.
2. Если истории нет (новый поставщик) или предпочтительный логист недоступен —
   наименее загруженный в группе (минимум заказов со статусом «в работе»).
3. Один поставщик в пачке — один логист.
4. Если в группе нет доступных логистов — заказ остаётся без логиста (в другую
   группу не передаётся), попадает в «Требует внимания».

## Сопоставление коротких имён Cloud с ФИО из 1С

- Короткое имя в Cloud: «Иванов И.» (фамилия + первая буква имени).
- Полное имя в 1С: «Иванов Иван Иванович».
- Совпадение: фамилия и первая буква имени.

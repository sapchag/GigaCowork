# GigaCowork — AI-агент распределения заказов между логистами

Тестовое задание на разработку AI-агента на платформе GigaCowork.

Агент принимает три выгрузки Excel (ФУЛ из 1С, реестр заказов Cloud, список
сотрудников из 1С) и по правилам заказчика:

- определяет **новые упаковочные листы (ФУЛ)** и отделяет **повторные отправки**;
- выбирает **группу логистов** по способу доставки и стране отправления;
- выбирает **логиста** с учётом истории работы с поставщиком, отпусков, увольнений
  и текущей загрузки;
- формирует **новые строки реестра Cloud** строго по его форме (12 колонок);
- подсвечивает заказы, по которым нужно **решение человека** (нет номера/группы/логиста).

Решение принимает **детерминированный скрипт навыка** (`agent/scripts/distribute.py`),
а не языковая модель. Модель (в GigaCowork) запускает навык и пересказывает результат.
Сеть и внешние интеграции не используются; только стандартная библиотека Python
и `openpyxl`/`xlrd`.

## Состав репозитория

```

  SKILL.md                # файл навыка (YAML-блок + инструкция модели)
  system_prompt.txt       # системный промпт агента
  scripts/                # distribute.py (правила), gigacowork_lib.py (утилиты)
  references/             # distribution_rules.md (справочник)
data/
  generate_data.py        # генератор синтетических данных и эталона (вымышленные данные)
  datasets/               # готовые наборы: set1 (full), set_trap, set_chk
tests/
  run_tests.py            # прогоны всех наборов по 3 раза + метрики
  compare_with_etalon.py  # сверка результата с эталоном
  metrics/                # test_metrics.json, result_cloud.xlsx по прогонам
docs/
  Инструкция_по_установке_и_запуску.md   # как установить и запустить
  scenarios_and_assumptions.md           # вопросы заказчику, алгоритм, допущения

  agent.zip               # навык, готовый к загрузке в GigaCowork

report/
  Отчёт_тестовое_задание_GigaCowork.pdf  # итоговый PDF-отчёт
```

## Запуск

Требования: Python 3.8+, `openpyxl`. Установка и запуск — в
[`docs/Инструкция_по_установке_и_запуску.md`](docs/Инструкция_по_установке_и_запуску.md).

Кратко — напрямую из командной строки:

```
python agent/scripts/distribute.py \
    --ful  <ФУЛ .xlsx> \
    --cloud <реестр Cloud .xlsx> \
    --staff <сотрудники .xlsx> \
    --out  <папка результата>
```

На выходе в папке результата — `result_cloud.xlsx` с листами:
**Новые строки Cloud**, **Повторные отправки**, **Возможные пропуски**,
**Требует внимания**, **Журнал решений**.

## Правила распределения

| Способ доставки | Страна отправления | Группа |
|---|---|---|
| `air` | любая | авиаперевозки |
| не `air` | Китай (вкл. Гонконг) | ВЭД |
| не `air` | не Китай | мультимодальные |
| нет / не определена | — | «не определено» → требует внимания |

Выбор логиста:

1. Исключаются сотрудники **в отпуске, уволенные, ассистенты и руководители**.
2. **Предпочтительный логист** — кто чаще всех работал с поставщиком (по истории в Cloud).
3. Иначе (новый поставщик / предпочтительный недоступен) — **наименее загруженный**
   в группе (минимум заказов «в работе»).
4. **Один поставщик в пачке — один логист.**
5. Если в группе нет доступных логистов — заказ остаётся без логиста, в другую группу
   не передаётся, попадает в «Требует внимания».
6. Короткие имена логистов Cloud сопоставляются с ФИО из 1С.

## Результаты контрольных прогонов

Каждый набор прогнан по 3 раза на одних и тех же файлах (детерминированный скрипт).

| Набор | ФУЛ | Точность (решение) | Точность (логист) | Точное совпадение | Воспроизводимость | Время |
|---|---|---|---|---|---|---|
| set1 (full)   | 16 | 1.00 | 1.00 | 1.00 | да | ~7.7 c |
| set_trap      | 15 | 1.00 | 1.00 | 1.00 | да | ~7.7 c |
| set_chk       | 16 | 1.00 | 1.00 | 1.00 | да | ~3.4 c |

На ловушках (нет номера заказа / страны / способа, вся группа недоступна) агент
**не выдумывает значения** — 0 выдуманных значений, всё переносится в «Требует
внимания» с причиной. Полная сводка — в `tests/metrics/test_metrics.json`.

## Воспроизведение тестов

```
python data/generate_data.py --out data/datasets/set1     --mode full --seed 42
python data/generate_data.py --out data/datasets/set_trap --mode trap --seed 42
python data/generate_data.py --out data/datasets/set_chk  --mode chk  --seed 42

python tests/run_tests.py \
    --datasets data/datasets/set1,data/datasets/set_trap,data/datasets/set_chk \
    --runs 3 \
    --distribute agent/scripts/distribute.py \
    --compare tests/compare_with_etalon.py \
    --out tests/metrics
```
